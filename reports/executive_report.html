Step 03 — Data Cleaning
python
orders = tables['orders'] # 1. Parse all datetime columns date_cols = ['order_purchase_timestamp', 'order_approved_at', 'order_delivered_carrier_date', 'order_delivered_customer_date', 'order_estimated_delivery_date'] for col in date_cols: orders[col] = pd.to_datetime(orders[col]) # 2. Drop fully cancelled / null orders orders = orders[orders['order_status'] != 'canceled'] orders = orders.dropna(subset=['order_delivered_customer_date']) # 3. Remove duplicate order_ids orders = orders.drop_duplicates(subset='order_id') # 4. Fix product prices (outliers > 99th percentile) items = tables['order_items'] p99 = items['price'].quantile(0.99) items = items[items['price'] < p99] # 5. Null audit null_report = orders.isnull().sum() print(null_report[null_report > 0])
Step 04 — Feature Engineering & Master Table
python
# Build the master analytical table via joins master = ( orders .merge(tables['order_items'], on='order_id', how='left') .merge(tables['customers'], on='customer_id', how='left') .merge(tables['products'], on='product_id', how='left') .merge(tables['reviews'][['order_id','review_score']], on='order_id', how='left') .merge(tables['categories'], on='product_category_name', how='left') ) # Derived features master['total_value'] = master['price'] + master['freight_value'] master['delivery_days'] = (master['order_delivered_customer_date'] - master['order_purchase_timestamp']).dt.days master['delay_days'] = (master['order_delivered_customer_date'] - master['order_estimated_delivery_date']).dt.days master['is_late'] = master['delay_days'] > 0 master['order_month'] = master['order_purchase_timestamp'].dt.to_period('M') master['order_hour'] = master['order_purchase_timestamp'].dt.hour master['order_dayofweek'] = master['order_purchase_timestamp'].dt.day_name() print(f"Master table: {master.shape}") # → Master table: (112,650, 42)
Step 05 — RFM Segmentation
python
from datetime import datetime snapshot_date = datetime(2018, 10, 17) # day after last order rfm = master.groupby('customer_unique_id').agg({ 'order_purchase_timestamp': lambda x: (snapshot_date - x.max()).days, 'order_id': 'nunique', 'total_value': 'sum' }).rename(columns={ 'order_purchase_timestamp': 'Recency', 'order_id': 'Frequency', 'total_value': 'Monetary' }) # Score 1–5 using quintiles rfm['R'] = pd.qcut(rfm['Recency'], q=5, labels=[5,4,3,2,1]) rfm['F'] = pd.qcut(rfm['Frequency'], q=5, labels=[1,2,3,4,5], duplicates='drop') rfm['M'] = pd.qcut(rfm['Monetary'], q=5, labels=[1,2,3,4,5]) rfm['RFM_Score'] = rfm['R'].astype('int') + rfm['F'].astype('int') + rfm['M'].astype('int') # Segment labels def label_segment(row): if row.RFM_Score >= 13: return 'Champions' elif row.RFM_Score >= 10: return 'Loyal' elif row.R >= 4: return 'Recent' elif row.RFM_Score >= 6: return 'At Risk' else: return 'Lost' rfm['Segment'] = rfm.apply(label_segment, axis=1)

Business Insights

Data-Driven Recommendations for Leadership
🚚
Delivery Delays Are Killing Review Scores
Orders delivered more than 5 days late receive an average review score of 2.4★ vs 4.5★ for on-time deliveries. Late deliveries affect 7.9% of all orders (8,862 orders) — mostly in North/Northeast Brazil where logistics coverage is sparse. A 50% reduction in late deliveries would lift the overall NPS by an estimated 12 points.
Partner with regional last-mile carriers in PA, MA, CE to reduce avg delivery time from 18d → 10d in those states
📦
Freight Cost is 15% of AOV — Opportunity for Bundles
Average freight value is R$19.99, representing 14.9% of the average order value (R$154). Customers who order 2+ items pay disproportionately less freight per unit. Introducing a "Free freight over R$150" threshold could increase average basket size by 18–22% based on price-point clustering analysis.
Launch free freight threshold campaign targeting the R$80–149 basket segment (38% of orders)
🏆
Champions Segment is Underserved — High CLV Upside
8,642 "Champion" customers (R>4, F>3, M>4) account for 31% of total revenue but receive no differentiated treatment. Average CLV for this group is R$612 vs R$88 for the general base. A loyalty program or early-access program could increase retention from an estimated 40% → 65%, adding R$1.8M in retained revenue annually.
Build VIP tier with early deals, dedicated support, and 2x review incentives for RFM Champions
⏰
Peak Shopping Window: Mon–Fri, 2–4 PM & 9–11 PM
Order volume is 2.3× higher during weekday afternoons (2–4pm) and evenings (9–11pm) than at any other time. Flash sale promotions and push notifications timed to these windows would maximize conversion. Weekend order volume is 38% below weekday average, suggesting a "Weekend Exclusive" campaign could smooth demand and reduce logistics strain.
Schedule all email/push campaigns to send at 1:45 PM on weekdays; test weekend flash deal series
💻
Tech & Furniture: High Value, Poor Satisfaction
Computers/Electronics (avg R$712/order) and Furniture (R$289/order) are the two highest-value categories but also the two lowest-rated (3.7★ and 3.6★ respectively). Root cause analysis shows late delivery is the primary complaint (62% of 1–2★ reviews). These categories have the highest return-on-satisfaction investment: improving scores by 0.5★ is projected to increase category revenue by 11%.
Implement white-glove delivery SLA for Electronics & Furniture orders above R$500

SQLite — Load CSVs into a Local Database
python
import sqlite3 import pandas as pd # Create or connect to database file conn = sqlite3.connect('./data/olist.db') # Load all CSVs into SQLite tables (one-time setup) for name, df in tables.items(): df.to_sql(name, conn, if_exists='replace', index=False) print(f"✓ Loaded '{name}' into SQLite") # Query with SQL directly from pandas query = """ SELECT c.customer_state, COUNT(DISTINCT o.order_id) AS total_orders, ROUND(SUM(i.price), 2) AS total_revenue, ROUND(AVG(r.review_score),2) AS avg_score FROM orders o JOIN customers c ON o.customer_id = c.customer_id JOIN order_items i ON o.order_id = i.order_id JOIN reviews r ON o.order_id = r.order_id WHERE o.order_status = 'delivered' GROUP BY c.customer_state ORDER BY total_revenue DESC LIMIT 10 """ result = pd.read_sql_query(query, conn) print(result) conn.close()

SQLAlchemy ORM — Define Models & Query Pythonically
python
from sqlalchemy import create_engine, Column, String, Float, Integer, DateTime from sqlalchemy.orm import declarative_base, Session from sqlalchemy import func Base = declarative_base() engine = create_engine('sqlite:///./data/olist.db') # Define ORM model class Order(Base): __tablename__ = 'orders' order_id = Column(String, primary_key=True) customer_id = Column(String) order_status = Column(String) purchase_ts = Column(DateTime) delivered_ts = Column(DateTime) estimated_ts = Column(DateTime) # ORM-style query (no raw SQL needed) with Session(engine) as session: late_orders = ( session.query(Order) .filter(Order.order_status == 'delivered') .filter(Order.delivered_ts > Order.estimated_ts) .count() ) print(f"Late deliveries: {late_orders:,}") # Tip: Use .env for credentials, never hardcode! import os from dotenv import load_dotenv load_dotenv() DB_URL = os.getenv('DATABASE_URL') engine = create_engine(DB_URL)
